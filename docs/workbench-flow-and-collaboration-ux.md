# 科研工作台路径与协作台优化说明

## 1. 今日优化目标

本轮优化围绕日报中的明日计划展开，目标是让 EnvInsight AI Pro 的科研工作台更像一个可执行的研究流程，而不是功能模块堆叠。

核心原则：

1. 左侧只负责菜单导航。
2. 右侧主区域承载具体任务。
3. 工作台按照“数据准备 → 模型分析 → 报告产出 → 协作留痕”推进。
4. 协作台要让用户明确知道自己当前身份能做什么、不能做什么。
5. 每个关键设计都要沉淀为文档和测试。

## 2. 核心使用路径

| 阶段 | 目标 | 完成标准 | 主要动作 | 风险控制 |
| --- | --- | --- | --- | --- |
| 数据准备 | 把研究问题、数据来源和合规状态先说明白 | 已有 CSV 或示例数据，并完成合规预审 | 上传数据或跑推荐示例数据 | 真实数据先审查字段风险，公开线索保留来源 |
| 模型分析 | 判断当前数据适合什么模型，结论是否足够稳健 | 已生成模型对比、可视化和 AI 解读 | 查看模型对比并运行情景模拟 | 提示相关性不等于因果性，样本不足时不强行下结论 |
| 报告产出 | 把分析结果沉淀成可复核、可导出的研究材料 | 已有结构化报告、论文初稿或资讯编辑草稿 | 生成结构化报告或论文初稿 | 输出必须包含证据链、局限说明和免责声明 |
| 协作留痕 | 让团队成员明确分工，把关键决策和复核动作留下来 | 已加入协作房间，任务、备注、决策和审计轨迹可追溯 | 创建房间、分配任务并记录决策 | 按角色限制任务、决策和审核动作，避免越权操作 |

## 3. 协作台体验优化

协作台从“一个表单 + 任务列表”优化为更明确的三步使用路径：

1. 建房间：输入房间号，也可以使用示例房间或当前数据集房间。
2. 选身份：负责人对应团队管理员，分析师对应研究员，复核人对应审核员。
3. 留痕迹：任务、备注、正式决策和协作历史分开沉淀。

新增交互：

- 房间快捷入口：示例房间、当前数据集房间、导入论文任务。
- 角色上手指引：展示当前身份可以做什么、需要注意什么、后续成长方向。
- 任务快捷模板：复核字段脱敏、补充模型局限、整理论文结果段。
- 备注快捷模板：数据初查、模型局限、发布复核提醒。
- 权限提醒：当用户没有创建任务或记录正式决策权限时，直接在界面提示替代路径。

## 4. 角色引导说明

| 角色 | 协作身份 | 页面引导重点 |
| --- | --- | --- |
| 普通用户 | 受邀访问者 | 先浏览资讯和体验示例数据，进入协作房间需要邀请 |
| 研究员 | 分析师 | 上传数据、查看模型分析、生成报告和补充协作备注 |
| 团队管理员 | 负责人 | 创建房间、管理任务、组织成员分工和查看审计轨迹 |
| 审核员 | 复核人 | 复核合规、记录正式决策、审核导出和公开发布风险 |

## 5. 测试覆盖

本轮补充和更新的测试重点：

- 工作台四阶段流程必须包含目标、完成标准、主要动作和风险控制。
- 左侧菜单仍然只能承载导航，不允许放回上传、协作、报告等功能区。
- 协作台必须在右侧主区域渲染。
- 协作台必须包含三步路径、角色上手指引、快捷任务、快捷备注和权限提醒。
- 用户权限模块必须提供角色上手指引，并与方案 B 的四类角色保持一致。

## 6. 后续计划

下一步可以继续推进：

1. 把当前前端角色选择升级为真实用户身份选择。
2. 增加团队成员邀请和项目空间概念。
3. 增加审核员专用审核队列。
4. 将报告导出、公开发布和协作决策接入统一审计日志。
