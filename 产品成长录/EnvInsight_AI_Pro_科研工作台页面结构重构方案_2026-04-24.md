# EnvInsight AI Pro 科研工作台页面结构重构方案

日期：2026-04-24

## 设计目标

- 让第一次进入工作台的用户知道“先做什么、后看什么”
- 把原来堆叠过长的模块改成分阶段浏览，降低认知负担
- 让高频任务优先出现：数据准备 -> 模型分析 -> 报告产出 -> 协作留痕
- 保留专业能力，但默认不把所有高级模块一次性摊开

## 用户最习惯的使用顺序

1. 先上传数据 / 导入论文线索
2. 先看合规与数据是否可用
3. 再看模型结果、图表和 AI 解读
4. 最后再导出报告、整理论文和进入协作

这比“把合规、建模、报告、协作并排堆满”更符合大多数用户的心理模型。

## 新页面结构图

```text
科研工作台
├─ 左侧：工作台控制台
│  ├─ 数据上传
│  ├─ 示例数据
│  ├─ 资讯导入线索
│  └─ 页面结构图 / 阶段导航
│
└─ 右侧：阶段化工作区
   ├─ 01 数据准备
   │  ├─ 当前输入状态
   │  ├─ 合规预审
   │  └─ AI 合规解决方案
   │
   ├─ 02 模型分析
   │  ├─ 核心指标总览
   │  ├─ 回归/散点图可视化
   │  ├─ 数据体检与多模型对比
   │  ├─ AI 智能解读
   │  └─ What-If 情景模拟
   │
   ├─ 03 报告产出
   │  ├─ 研究结果回流资讯（仅编辑草稿）
   │  ├─ 结构化报告
   │  └─ 论文初稿
   │
   └─ 04 协作留痕
      ├─ 多人协作研究室
      └─ 审计轨迹
```

## 每一屏只回答一个问题

### 01 数据准备
回答：这份数据能不能分析？要分析什么？

### 02 模型分析
回答：结果是什么？哪个模型更合适？AI 怎么解释？

### 03 报告产出
回答：如何把结果整理成可交付内容？

### 04 协作留痕
回答：团队如何分工、复核和追踪？

## 本次重构落地原则

- 左侧只保留“控制台”和“阶段导航”，避免左侧变成第二个长页面
- 右侧顶部增加总览 Hero 和 4 个阶段切换卡
- 非当前阶段内容默认隐藏，减少滚动距离
- 工作台结论不再直接发布到大众资讯流，只生成编辑草稿
- 资讯端文案统一朝“大众能一眼看懂”优化

## 后续可继续优化的点

- 为每个阶段增加完成进度条
- 把“模型分析”再细分为“结果总览 / 高级模型 / AI 解读”三级视图
- 给“报告产出”增加固定导出栏
- 给“协作留痕”增加角色过滤和按成员查看视图
